# Recipe Manager

自分専用のレシピ管理アプリです。

## 目的

料理のレシピを登録・管理し、iPhoneとPCの両方から利用できるようにする。

## 公開URL

- https://naoto688.github.io/recipe-manager/

## 主な機能

- レシピの登録
- レシピの一覧表示
- レシピの詳細表示
- レシピの編集・削除
- レシピの検索
- カテゴリー分類
- お気に入り登録
- クラウドデータ同期（PC・iPhone共有）
- 写真の登録

## 技術構成

- CSS
- JavaScript
